# Pembrolizumab in trial-ineligible patients with metastatic urothelial carcinoma

R code for the analysis reported in:

> Effectiveness of pembrolizumab in trial-ineligible patients with metastatic urothelial carcinoma. *Cancer Immunology, Immunotherapy*. <https://link.springer.com/article/10.1007/s00262-022-03291-5>

Multicenter retrospective cohort of 164 patients; KEYNOTE-045-ineligible and eligible patients compared on overall and progression-free survival with inverse probability of treatment weighting and restricted mean survival times.

## Contents

- `script.qmd`: analysis
- `manuscript_file.qmd`: manuscript source

## Requirements

R 4.x with `ggconsort`.

## Data

Patient-level data are not included in this repository.
